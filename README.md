# Loja-Apple
Ao iniciar meus estudos no curso de formação em desenvolvedor full stack com Matheus Battisti sensei, comecei a entender sobre criação de sites em HTML e CSS. Seus ensinamentos são maravilhosos e os projetos também. Em cada aprendizado um desafio em seguida para demonstrar as habilidades aprendidas. Então comecei a desempenhá-los sem resitar, no início tive receio de errar. Mas como o Matheus sensei e a equipe de suporte diz; errar nunca foi um ponto negativo, mas sim, um ponto positivo onde você aprende a resolver erros, bugs.

Dessa forma aprende-se a desenvolver melhor suas qualidades, seu raciocinio lógico, interpretação de um projeto e escolhe a melhor implementação para criar uma página web.
